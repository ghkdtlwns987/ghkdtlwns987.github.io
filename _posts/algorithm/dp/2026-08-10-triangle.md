## 문제 설명

삼각형의 꼭대기에서 바닥까지 이어지는 경로 중, 거쳐간 숫자의 합이 **가장 큰** 경우를 찾습니다. 아래 칸으로 이동할 때는 대각선으로 **한 칸 왼쪽 또는 오른쪽**만 가능합니다. 예를 들어 3에서는 아래의 8 또는 1로만 갈 수 있습니다.

```
      7
     3 8
    8 1 0
   2 7 4 4
  4 5 2 6 5
```

`triangle`이 주어질 때 거쳐간 숫자의 최댓값을 return 하세요.

제한사항
- 높이는 1 이상 500 이하
- 숫자는 0 이상 9,999 이하

입출력 예

| triangle | result |
| --- | --- |
| [[7], [3, 8], [8, 1, 0], [2, 7, 4, 4], [4, 5, 2, 6, 5]] | 30 |

한 경로 예: 7 → 3 → 8 → 7 → 5 = 30. 이보다 큰 합은 없습니다.

---

## DFS/BFS가 아니라 DP인 이유

한 칸에서 내려가는 분기가 2개고, 높이가 최대 500이다. 모든 경로를 탐색하면 최악의 경우 **2⁵⁰⁰**. [게임 맵 최단거리]({{ '/poster/2026/09/01/game-map-shortest-path/' | relative_url }})처럼 격자를 한 번씩만 방문하는 BFS도 아니다. 같은 칸에 **서로 다른 경로**로 올 수 있고, 필요한 것은 그 칸까지의 **합의 최댓값**이다.

그래서 칸마다 한 숫자만 남긴다.

```text
dp[i][j] = (i행 j열에 도착했을 때, 지금까지 합의 최댓값)
```

아래 칸 `(i, j)`로 올 수 있는 곳은 바로 위 두 칸뿐이다.

```text
     (i-1, j-1)   (i-1, j)
              \   /
             (i, j)
```

- 왼쪽 끝 `j == 0` : 위는 `(i-1, 0)`만
- 오른쪽 끝 `j == i` : 위는 `(i-1, j-1)`만
- 가운데 : 둘 중 **큰 쪽** + 지금 칸

```text
dp[i][j] = triangle[i][j] + max(위왼쪽, 위오른쪽)
           (있는 것만)
```

바닥 행 `dp[n-1]`의 최댓값이 답이다.

---

## 행·열 이름을 헷갈리지 않기

코드에서 바깥 반복이 `col`, 안이 `row`로 되어 있어도, 실제 의미는 **바깥이 층(행), 안이 그 층에서의 위치(열)** 이다. [게임 맵 최단거리]({{ '/poster/2026/09/01/game-map-shortest-path/' | relative_url }})의 n(행)/m(열)과 같이, 변수 이름보다 **인덱스가 무엇을 가리키는지**가 중요하다.

```text
triangle[i][j]     i = 위에서부터 몇 번째 줄 (0부터)
                   j = 그 줄에서 왼쪽부터 몇 번째 (0부터)

i번째 줄의 길이는 i + 1
  triangle[0] = [7]
  triangle[1] = [3, 8]
  triangle[4] = [4, 5, 2, 6, 5]
```

`dp`를 `n × n`으로 잡아 두고, i번째 줄은 앞의 `i + 1`칸만 쓴다. 나머지 0은 답이 아니다.

---

## 로직 흐름

꼭대기와 그다음 줄은 경로가 하나라 바로 채울 수 있다.

```text
dp[0][0] = 7
dp[1][0] = 7+3 = 10
dp[1][1] = 7+8 = 15
```

3번째 줄부터:

```text
      7
    10  15
   18  16  15     ← 8+10, max(10,15)+1, 0+15
  20  25  20  19
 24  30  27  26  24
```

맨 아래 최댓값 30.

왼쪽 끝은 항상 `dp[i-1][0]`에서만 오고, 오른쪽 끝은 `dp[i-1][i-1]`에서만 온다. 가운데는 두 후보의 max.

높이 1이면 `triangle[1]`이 없어서, 2행을 미리 채우는 코드는 **높이가 2 이상일 때** 성립한다. 높이 1이면 `return triangle[0][0]`이면 된다.

---

### Solution

```python
def solution(triangle):
    n = len(triangle)
    dp = [[0] * n for _ in range(n)]

    dp[0][0] = triangle[0][0]
    dp[1][0] = dp[0][0] + triangle[1][0]
    dp[1][1] = dp[0][0] + triangle[1][1]

    for col in range(2, len(triangle)):
        for row in range(len(triangle[col])):
            if row == 0:
                dp[col][row] = dp[col - 1][row] + triangle[col][row]
            elif row == len(triangle[col]) - 1:
                dp[col][row] = dp[col - 1][row - 1] + triangle[col][row]
            else:
                dp[col][row] = max(
                    dp[col - 1][row - 1] + triangle[col][row],
                    dp[col - 1][row] + triangle[col][row]
                )

    return max(dp[n - 1])
```

- `dp[i][j]` : i줄 j칸까지 경로 합의 최댓값
- `row == 0` / 마지막 : 가장자리. 위칸이 하나뿐
- 가운데 : `dp[위][j-1]`, `dp[위][j]` 중 큰 값 + 지금 칸
- 답은 **마지막 줄**의 최댓값 `max(dp[n - 1])`

`max(max(dp))`는 행을 **사전순**으로 고른 뒤 그 행의 최댓값을 낸다. 전역 최댓값이 아니다. 숫자는 0 이상이라 마지막 줄이 대체로 크지만, 중간 줄이 사전순으로 더 앞설 수 있다. 바닥 행만 보면 된다.

1줄부터 같은 점화식으로 돌려도 된다. 0줄만 초기화하고 `for i in range(1, n)` 하면 높이 1도 그대로 통과한다.

```python
dp[0][0] = triangle[0][0]
for i in range(1, n):
    ...
```

## 정리

| 키워드 | 내용 |
| --- | --- |
| 알고리즘 | DP (경로 최댓값) |
| 상태 | `dp[i][j]` = (i, j)까지 합의 최댓값 |
| 전이 | 위왼쪽 / 위오른쪽 중 큰 값 + `triangle[i][j]` |
| 가장자리 | 왼쪽은 위만, 오른쪽은 위왼쪽만 |
| 답 | `max(dp[마지막 줄])` |
| 복잡도 | O(n²), n ≤ 500 |

경로 개수가 지수여도, 칸마다 "여기까지 최댓값"만 남기면 된다. 같은 칸에 더 작은 합으로 도착한 경로는 이후에도 이길 수 없다.
